# KamiLash & Brow

Prémium szempilla lifting és szemöldök laminálás weboldal interaktív online időpontfoglaló rendszerrel.

## Technológiai Stack
- Tiszta HTML5, CSS3, Vanilla JS (Static site, Vercel-ready)
- Playfair Display + Inter tipográfia
- Interaktív időpontfoglaló motor (.ics & Google Calendar exporttal)
- Előtte-Utána interaktív összehasonlító csúszka
- 1148 Budapest, Lengyel u. 16. (Zugló)
